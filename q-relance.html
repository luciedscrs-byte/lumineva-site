Faut-il relancer après la 1re commande, et quand ?

Les clients reviennent peu et tard : on regarde quand les relancer et ce que cela peut rapporter.

En sept lignes

ÉtapePour cette question
La questionFaut-il relancer un client après sa 1re commande, et quand ?
L’hypothèseUne relance avant le délai médian de retour fait revenir des clients qui ne seraient pas revenus seuls.
Le périmètre913 clients (23 juin 2025 au 22 octobre 2026) ; cible : environ 474 clients joignables par an.
Le testCourbe de retour (Kaplan-Meier), comparaison 1re et 2e commande (Wilcoxon), arbre de décision (AUC), taille d’échantillon.
L’effet11 % ont recommandé à J+45, 21 % à J+90 ; 2e commande +3,76 € ; aucun critère ne prédit le retour (AUC 0,55).
Le chiffreGain prudent (+1 à +2 points de retour) : 115 € à 321 € de marge par an.
La décisionRelancer tous les clients à une commande, à J+45, sans remise, avec un produit voisin.

Niveau de preuve : Démontré pour le délai de retour ; Hypothèse pour le gain (l’effet de la relance n’est pas mesuré)

Quelle part des clients a recommandé, jour après jour ?

913 clients suivis ; les clients récents sont gardés « en attente » (méthode de Kaplan-Meier).

Ce que pourrait rapporter la relance

Effet supposé, non mesuré. Montants facturés (TVA et livraison comprises) : les marges sont des plafonds.

Retour en plusCommandes par anChiffre d’affairesMarge (36 à 50 %)
+1 point5321 €115 € à 161 €
+2 points10642 €229 € à 321 €
+5 points241 605 €573 € à 803 €
  • FaitLe panier monte de 3,76 € à la 2e commande, par le prix des articles (+0,16 € par article), pas par leur nombre (p = 0,028). 25 % rachètent le même produit, 81 % la même famille.
  • Fait49 % des 1res commandes utilisent déjà le code de bienvenue : une relance avec remise s’adresse à des clients déjà remisés.
  • Interprétation possibleJ+45 est un compromis raisonné : avant le délai médian, quand le retour naturel (environ 8 % dans les 30 jours suivants) reste faible. Il n’est pas démontré.
  • LimiteLe scénario à +5 points (573 € à 803 €) suppose 5 commandes pour 100 e-mails, plus du double de ce que les relances panier obtiennent (1,0 commande pour 100 e-mails) : c’est le cas favorable.

Ce qu’on conseille

  • Relancer à J+45, sans remise, en proposant un produit voisin de ce que le client a acheté.
  • Suivre le retour à J+90 des clients relancés : un test A/B est impossible (il faudrait environ 603 clients par groupe, plus de deux ans de flux).

Limites et ce qui manque

  • L’effet réel d’une relance est inconnu : les gains sont des hypothèses.
  • Les montants incluent livraison (6 %) et TVA (5 % du total, 16 % depuis le 28 mai 2026) : la marge réelle est plus basse.
  • On ne sait pas si les 50 % de marge sont calculés hors taxes.

"""Relance après la 1re commande : quand l'envoyer, combien de clients visés, et ce qu'elle pourrait rapporter (scénarios).
Aucune donnée personnelle : comptes et délais agrégés."""
import csv, json, os
from datetime import datetime, timedelta
import numpy as np
from common import charger, REF

cmds, clients = charger()
cm = {r['customer_key']: r for r in csv.DictReader(open('../DONNEES/customers.csv', encoding='utf-8'))}
rows = []
for k, os_ in clients.items():
    p = os_[0]; d1 = p['dt']
    d2 = os_[1]['dt'] if len(os_) > 1 else None
    rows.append({'k': k, 'd1': d1, 'jours': (d2 - d1).days if d2 else None, 'suivi': (REF - d1).days, 'cons': cm.get(k, {}).get('Accepts Email Marketing') == 'yes', 'b2': os_[1]['total'] if d2 else None})
N = len(rows); ret = [r for r in rows if r['jours'] is not None]
print('clients', N, '| ont recommandé', len(ret))

# ---------- Kaplan-Meier du délai avant la 2e commande (censure à la date de référence)
dur = np.array([r['jours'] if r['jours'] is not None else r['suivi'] for r in rows], dtype=float); ev = np.array([1 if r['jours'] is not None else 0 for r in rows])
def km(dur, ev, tmax=400):
    ts = sorted(set(dur[ev == 1])); S = 1.0; pts = [(0, 1.0)]; var_acc = 0.0; ci = []
    for t in ts:
        if t > tmax: break
        n_risk = (dur >= t).sum(); d = ((dur == t) & (ev == 1)).sum()
        S *= (1 - d / n_risk); var_acc += d / (n_risk * (n_risk - d)) if n_risk > d else 0
        pts.append((float(t), float(S))); ci.append((float(t), float(S), float(S * np.sqrt(var_acc))))
    return pts, ci
pts, ci = km(dur, ev)
def S_at(t):
    s = 1.0
    for tt, ss in pts:
        if tt <= t: s = ss
        else: break
    return s
def se_at(t):
    e = 0.0
    for tt, ss, se in ci:
        if tt <= t: e = se
        else: break
    return e
retour = {t: 1 - S_at(t) for t in (30, 45, 60, 90, 120, 180)}
print('part ayant recommandé à J+t (Kaplan-Meier) :', {t: round(100 * v, 1) for t, v in retour.items()})
cond = {}
for t0 in (30, 45, 60):
    s0 = S_at(t0)
    cond[t0] = {t: float((s0 - S_at(t)) / s0) for t in (t0 + 30, t0 + 60)}
print('retour dans les 30 et 60 jours suivants parmi ceux qui n\'ont pas encore recommandé :', {t0: {t: round(100 * v, 1) for t, v in d.items()} for t0, d in cond.items()})
# histogramme des délais parmi ceux qui reviennent
bornes = [0, 15, 30, 45, 60, 75, 90, 120, 180, 400]
hist = []
for a, b in zip(bornes[:-1], bornes[1:]):
    hist.append({'a': a, 'b': b, 'n': sum(1 for r in ret if a <= r['jours'] < b)})
print('délais parmi les 248 qui reviennent :', [(h['a'], h['n']) for h in hist], '| médiane', np.median([r['jours'] for r in ret]))

# ---------- cible : clients à 1 commande à J+45 (flux annuel) et joignables par e-mail
ANNEE = [r for r in rows if r['suivi'] >= 45 and r['suivi'] <= 45 + 365]               # premiers achats des 12 mois se terminant à J-45
def pas_encore(r, t0): return r['jours'] is None or r['jours'] > t0
cibles = {}
for t0 in (30, 45, 60):
    pool = [r for r in rows if r['suivi'] >= t0 + 1 and r['suivi'] <= t0 + 365]
    elig = [r for r in pool if pas_encore(r, t0)]; join = [r for r in elig if r['cons']]
    cibles[t0] = {'achats_12m': len(pool), 'sans_retour': len(elig), 'joignables': len(join), 'part_joignables': len(join) / len(elig) if elig else 0}
print('cibles par moment d\'envoi :', cibles)
# situation actuelle : clients dans la fenêtre 45-90 jours aujourd'hui
actuel = [r for r in rows if 45 <= r['suivi'] <= 90 and r['jours'] is None]
print('aujourd’hui : clients à 1 commande entre 45 et 90 jours :', len(actuel), 'dont joignables', sum(r['cons'] for r in actuel))
b2 = float(np.mean([r['b2'] for r in ret])); b1 = float(np.mean([r['b2'] for r in ret]))
panier2 = b2

# ---------- scénarios : points de retour en plus parmi les joignables à J+45
MB, MH = 0.50 * 0.714, 0.50
t0 = 45; c = cibles[t0]; base_p = cond[45][75]                                           # retour naturel dans les 30 jours suivants (J+45 à J+75)
sc = []
for delta in (0.02, 0.05, 0.10):
    extra = c['joignables'] * delta; ca = extra * panier2
    sans_remise = {'cmd': extra, 'ca': ca, 'marge_bas': ca * MB, 'marge_haut': ca * MH}
    remise = 0.10                                                                          # code de 10 % donné à tous ceux qui reviennent dans les 30 jours
    cout = remise * panier2 * (c['joignables'] * (base_p + delta))
    avec = {'cmd': extra, 'ca': ca, 'cout_remise': cout, 'marge_bas': ca * MB - cout, 'marge_haut': ca * MH - cout}
    sc.append({'delta': delta, 'sans': sans_remise, 'avec': avec})
    print(f'  +{100*delta:.0f} points : {extra:.1f} commandes en plus/an, {ca:,.0f} € de CA ; sans remise marge {ca*MB:,.0f}-{ca*MH:,.0f} € ; avec 10 % : coût {cout:,.0f} € -> marge {ca*MB-cout:,.0f} à {ca*MH-cout:,.0f} €')
print('retour naturel J+45→J+75 :', round(100 * base_p, 1), '% | panier moyen de la 2e commande :', round(panier2, 2))
json.dump({'N': N, 'n_ret': len(ret), 'mediane': float(np.median([r['jours'] for r in ret])), 'retour': {str(k): v for k, v in retour.items()}, 'cond': {str(a): {str(b): v for b, v in d.items()} for a, d in cond.items()},

# encoding: utf-8
"""Que change-t-il entre la 1re commande d'un client et les suivantes (prix, quantité, produits) ?"""
import json
import numpy as np
from collections import defaultdict, Counter
from scipy import stats
from common import charger, FAMILLES

commandes, clients = charger()
rec = {k: v for k, v in clients.items() if len(v) >= 2}          # clients ayant recommandé
print(len(rec), 'clients récurrents')

def resume(orders):
    tot = [o['total'] for o in orders]; q = [o['qte'] for o in orders]
    pu = [o['prix_unit'] for o in orders if o['prix_unit']]
    fam_par_cmd = [len(o['familles']) for o in orders]
    return {
        'n': len(orders), 'total_moy': round(np.mean(tot), 2), 'total_med': round(float(np.median(tot)), 2),
        'qte_moy': round(np.mean(q), 2), 'prix_unit_moy': round(np.mean(pu), 2),
        'fam_moy': round(np.mean(fam_par_cmd), 2),
        'pct_code': round(100 * np.mean([1 if o['code'] else 0 for o in orders]), 1),
        'pct_local': round(100 * np.mean([o['local'] for o in orders]), 1),
        'pct_multi_fam': round(100 * np.mean([1 if len(o['familles']) >= 2 else 0 for o in orders]), 1),
    }

# --- A) Profil moyen des commandes selon leur rang, chez les clients qui reviennent
par_rang = {'1re': [], '2e': [], '3e': [], '4e et +': []}
for v in rec.values():
    for o in v:
        k = '1re' if o['rang'] == 1 else '2e' if o['rang'] == 2 else '3e' if o['rang'] == 3 else '4e et +'
        par_rang[k].append(o)
tab_rang = {k: resume(v) for k, v in par_rang.items() if v}
# repère : 1re commande des clients qui ne reviennent pas (tous, y compris récents)
uniques = [v[0] for k, v in clients.items() if len(v) == 1]
tab_rang['Client à 1 seule commande'] = resume(uniques)
for k, v in tab_rang.items(): print(k, v)

# part de chaque famille dans les commandes selon le rang
fam_part = {}
for k, orders in par_rang.items():
    if not orders: continue
    c = Counter(f for o in orders for f in o['familles'])
    fam_part[k] = {f: round(100 * c[f] / len(orders), 1) for f in FAMILLES}

# --- B) Comparaison appariée : la 1re et la 2e commande du MÊME client
p1 = [v[0] for v in rec.values()]; p2 = [v[1] for v in rec.values()]
def pair(champ):
    a = np.array([o[champ] for o in p1], dtype=float); b = np.array([o[champ] for o in p2], dtype=float)
    d = b - a
    w, pw = stats.wilcoxon(d) if np.any(d != 0) else (0, 1)
    return {'moy1': round(a.mean(), 2), 'moy2': round(b.mean(), 2), 'delta_moy': round(d.mean(), 2),
            'delta_med': round(float(np.median(d)), 2), 'wilcoxon_p': float(pw),
            'plus': int((d > 0).sum()), 'moins': int((d < 0).sum()), 'egal': int((d == 0).sum())}
paired = {'total': pair('total'), 'qte': pair('qte')}
pu1 = np.array([o['prix_unit'] for o in p1]); pu2 = np.array([o['prix_unit'] for o in p2])
d = pu2 - pu1; w, pw = stats.wilcoxon(d)
paired['prix_unit'] = {'moy1': round(pu1.mean(), 2), 'moy2': round(pu2.mean(), 2), 'delta_moy': round(d.mean(), 2),
                       'delta_med': round(float(np.median(d)), 2), 'wilcoxon_p': float(pw),
                       'plus': int((d > 0).sum()), 'moins': int((d < 0).sum()), 'egal': int((d == 0).sum())}
print('appariés', json.dumps(paired, ensure_ascii=False)[:600])

# --- C) Ce qu'on rachète : mêmes produits / mêmes familles entre la 1re et la 2e commande
meme_prod = sum(1 for a, b in zip(p1, p2) if set(a['produits']) & set(b['produits']))
meme_fam = sum(1 for a, b in zip(p1, p2) if set(a['familles']) & set(b['familles']))
meme_fam_dom = sum(1 for a, b in zip(p1, p2) if a['fam_dom'] == b['fam_dom'])
# part des produits de la 2e commande qui étaient déjà dans la 1re
deja = sum(len(set(b['produits']) & set(a['produits'])) for a, b in zip(p1, p2))
tot_prod2 = sum(len(b['produits']) for b in p2)
# variété : nouveaux produits jamais achetés avant, sur l'ensemble des commandes suivantes
nouv_fam = sum(1 for a, b in zip(p1, p2) if set(b['familles']) - set(a['familles']))
recompra = {'n': len(rec), 'meme_produit': meme_prod, 'meme_famille': meme_fam, 'meme_famille_dominante': meme_fam_dom,
            'part_produits_deja_achetes': round(100 * deja / tot_prod2, 1), 'avec_nouvelle_famille': nouv_fam}
print('rachat', recompra)

# --- D) Matrice famille dominante 1re commande -> 2e commande (lignes = 1re)
mat = defaultdict(Counter)
for a, b in zip(p1, p2): mat[a['fam_dom']][b['fam_dom']] += 1
matrice = {f: {g: mat[f][g] for g in FAMILLES} for f in FAMILLES if sum(mat[f].values()) > 0}
tot_ligne = {f: sum(matrice[f].values()) for f in matrice}

# --- E) trajectoire de prix : le 2e panier est-il plus grand, plus petit, égal ?
delta_tot = [b['total'] - a['total'] for a, b in zip(p1, p2)]
plus = sum(1 for d in delta_tot if d > 5); moins = sum(1 for d in delta_tot if d < -5); stable = len(delta_tot) - plus - moins

json.dump({'tab_rang': tab_rang, 'fam_part': fam_part, 'paired': paired, 'recompra': recompra,
           'matrice': matrice, 'tot_ligne': tot_ligne, 'trajectoire': {'plus': plus, 'moins': moins, 'stable': stable, 'n': len(delta_tot)}},
          open('g1_premiere_vs_suivantes.json', 'w'), ensure_ascii=False)

"""Profils de clients : fiche par client (habitudes, ville, niveau de vie), segmentation automatique (k-means),

from common import charger, REF

commandes, clients = charger()

# ---- niveau de vie : médiane du niveau de vie de la commune (Insee-Filosofi 2020), à défaut du département
def lire(f):
    d = {}
    for r in csv.DictReader(open(f, encoding='utf-8'), delimiter=';'):
        try: d[r['CODGEO']] = float(r['MED20'].replace(',', '.'))
        except Exception: pass
    return d
inc_com = lire('cache/cc_filosofi_2020_COM.csv'); inc_dep = lire('cache/cc_filosofi_2020_DEP.csv')
comm_cp = json.load(open('cache/communes_par_cp.json'))

def geo(cp):
    cs = comm_cp.get(cp) or []
    if not cs: return None
    c = max(cs, key=lambda x: x.get('population') or 0)
    dep = c.get('codeDepartement') or cp[:2]
    inc = inc_com.get(c['code']); src = 'commune'
    if inc is None:
        inc = inc_dep.get(dep); src = 'département'
    return {'commune': c['nom'], 'pop': c.get('population') or 0, 'dep': dep, 'revenu': inc, 'src_revenu': src}

def taille(p):
    return 'Village (< 2 000 hab.)' if p < 2000 else 'Petite ville (2 000 à 20 000)' if p < 20000 else 'Ville (20 000 à 100 000)' if p < 100000 else 'Grande ville (> 100 000)'

# ---- paiement par commande
pay = {}
for r in csv.DictReader(open('../DONNEES/payment_transactions.csv', encoding='utf-8')):
    if r['Type'] == 'charge' and r['order_key'] not in pay: pay[r['order_key']] = r['Payment Method Name']

for k, os_ in clients.items():

    g = geo(p['cp']) if p['pays'] == 'FR' else None
    fam_dist = set(f for o in os_ for f in o['familles'])
    dep_first = p['cp'][:2]
    f = {
        'cle': k, 'n': len(os_), 'depense': sum(o['total'] for o in os_),
        'panier': float(np.mean([o['total'] for o in os_])), 'recence': (REF - os_[-1]['dt']).days,

        'n_fam': len(fam_dist), 'pays': p['pays'], 'geo': g,
        'p_qte': p['qte'], 'p_total': p['total'], 'p_code': 1 if p['code'] else 0, 'p_local': p['local'],
        'p_we': 1 if p['dt'].weekday() >= 5 else 0, 'p_paypal': 1 if pay.get(p['ordre_key']) == 'paypal' else 0,
        'p_nfam': len(p['familles']), 'p_gourmande': 1 if 'Bougies gourmandes' in p['familles'] else 0,

    fiches.append(f)
print(len(fiches), 'fiches clients ;', sum(1 for f in fiches if f['geo']), 'avec ville/niveau de vie')

# imputation simple : médiane nationale pour les clients sans géolocalisation (Belgique, etc.)
med_rev = float(np.median([f['geo']['revenu'] for f in fiches if f['geo'] and f['geo']['revenu']]))
med_pop = float(np.median([f['geo']['pop'] for f in fiches if f['geo']]))
for f in fiches:

cols = ['ln_n', 'ln_dep', 'ln_panier', 'recence', 'pct_local', 'pct_code', 'n_fam', 'revenu', 'ln_pop', 'pct_we']

"""Base commune aux analyses de parcours client : lecture de orders.csv (hors commandes annulées),
familles de produits, clés produit, commandes rangées par client."""
import csv, re
from datetime import datetime
from collections import defaultdict

ORDERS_CSV = '../DONNEES/orders.csv'
REF = datetime(2026, 10, 23)

FAMILLES = ['Bougies gourmandes', 'Bougies boisson', 'Bougies taille S', 'Autres bougies', 'Fondants',
            'Voiture', 'Diffuseurs maison', 'Poudre parfumée', 'Élixirs', 'Accessoires et cadeaux', 'Formation']

def famille(name):
    n = name.upper()
    if n.startswith('BOUGIE GOURMANDE'): return 'Bougies gourmandes'
    if n.startswith(('BOUGIE BOISSON', 'BOUGIE LATTE', 'BOUGIE ICED')): return 'Bougies boisson'
    if n.startswith('BOUGIE PARFUMEE TAILLE S'): return 'Bougies taille S'
    if n.startswith('BOUGIE'): return 'Autres bougies'
    if n.startswith(('BOX DE FONDANTS', 'BOUQUET DE FONDANTS', 'TABLETTE', 'FONDANT')): return 'Fondants'
    if n.startswith(('SUSPENSION VOITURE', 'DIFFUSEUR VOITURE')): return 'Voiture'
    if n.startswith(('DIFFUSEUR', 'RECHARGE MELANGE')): return 'Diffuseurs maison'
    if n.startswith('POUDRE'): return 'Poudre parfumée'
    if n.startswith('ELIXIR'): return 'Élixirs'
    if n.startswith(('PACK FABRICATION', 'PACK BOUGIES')) or 'CONSULTING' in n or n.startswith('RÉGLEMENTATION') or n.startswith('REGLEMENTATION'): return 'Formation'
    return 'Accessoires et cadeaux'

def cle_produit(name):
    """Produit au sens marketing : on retire la variante après ' - ' ou ' / ' (parfum, taille)."""
    return re.split(r' - | / ', name)[0].strip()

def joli(s):
    t = s.replace('BOUGIE GOURMANDE ', 'Bougie ')
    t = t.translate(str.maketrans('ÉÈÊÀÂÎÔÛÇÏËÖ', 'éèêàâîôûçïëö')).lower()
    return t[0].upper() + t[1:]

def charger():
    """Retourne (commandes, clients) : commandes = liste de dicts ; clients = {cle: [commandes triées par date]}."""
    rows = []
    cur = None
    with open(ORDERS_CSV, encoding='utf-8') as f:
        for r in csv.DictReader(f):
            if r['Total']:
                cur = {'r': r, 'lignes': []}
                rows.append(cur)
            if cur and r['Lineitem name'] and r['Lineitem name'] != 'Tip':
                cur['lignes'].append({'nom': r['Lineitem name'], 'qte': int(r['Lineitem quantity']), 'prix': float(r['Lineitem price'])})
    commandes = []
    for o in rows:
        r = o['r']
        if r.get('Cancelled at'): continue
        sm = r['Shipping Method'] or ''
        d = {
            'date': r['Created at'][:10], 'dt': datetime.strptime(r['Created at'][:19], '%Y-%m-%d %H:%M:%S'),
            'cle': r['customer_key'].strip(), 'total': float(r['Total']), 'sous_total': float(r['Subtotal']),
            'code': r['Discount Code'] or '', 'remise': float(r['Discount Amount'] or 0),
            'local': 1 if re.match(r'^\d|otissement', sm) else 0,
            'pays': (r['Shipping Country'] or r['Billing Country'] or '').strip(),
            'cp': re.sub(r'\D', '', (r['Shipping Zip'] or r['Billing Zip'] or '')).zfill(5)[:5],
            'ordre_key': r['order_key'],
            'lignes': o['lignes'],
        }
        d['qte'] = sum(l['qte'] for l in d['lignes'])
        d['familles'] = sorted(set(famille(l['nom']) for l in d['lignes']))
        d['produits'] = sorted(set(cle_produit(l['nom']) for l in d['lignes']))
        val = defaultdict(float)
        for l in d['lignes']: val[famille(l['nom'])] += l['qte'] * l['prix']
        d['fam_dom'] = max(val.items(), key=lambda kv: kv[1])[0] if val else None
        d['prix_unit'] = (d['sous_total'] / d['qte']) if d['qte'] else None
        commandes.append(d)
    clients = defaultdict(list)
    for d in commandes:
        if d['cle'] and d['lignes']: clients[d['cle']].append(d)
    for v in clients.values(): v.sort(key=lambda d: d['dt'])
    for v in clients.values():
        for i, d in enumerate(v): d['rang'] = i + 1
    return commandes, clients
