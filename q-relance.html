1

La question

La décision à prendre, posée en une phrase.

Faut-il relancer un client après sa 1re commande, et à quel moment ?

Pourquoi cette question ?

Constat 1 de « Choix et données » : 69 % des clients n’ont commandé qu’une fois. La gérante veut vendre plus sans plus de travail : une relance qui part seule répond à ce besoin.

2

L’hypothèse

Ce qu’on pense avant de calculer : c’est ce qu’on va vérifier.

Plus un client reste silencieux, moins il a de chances de recommander : il y a donc un moment où écrire.

Notre hypothèse

Si la chance de retour baisse avec le temps, un e-mail envoyé avant cette baisse a plus d’utilité qu’un e-mail envoyé après. Les clients qui reviennent vite sont peut-être aussi ceux qui deviendront fidèles.

Comment lire la valeur p ?

La valeur p est la chance de voir un tel écart si les deux groupes étaient en réalité identiques. Sous 5 %, on dit que l’écart est réel. Elle ne dit pas si l’écart est important : on regarde donc aussi sa taille (ici 16 points).

6

Le chiffre

Ce que ça vaut en euros.

0,9 à 7,6 commandes par an, soit 54 à 474 € de chiffre d’affaires (hypothèse, voir le bilan dans Recommandations).

Pourquoi ces 5 moments d’envoi ?

Notre règle : écrire avant que la chance de retour ne baisse, mais pas trop tôt. Trop tôt, on écrit à un client qui allait commander seul ; trop tard, il a déjà oublié. Les chiffres ci-dessous donnent les 5 moments, et ces 5 moments donnent le nombre d’e-mails du calcul qui suit.

J+45

Il vient d’essayer

Après sa 1re commande. Chance de commander dans le mois : 8,4 % à J+45, 5,9 % à J+60 : elle baisse ensuite. À J+45, 34 % (94 sur 280) de ceux qui reviendront un jour sont déjà revenus : le mail vise les autres.

Après sa 2e commande. Entre la 2e et la 3e commande, il attend 47 jours en médiane. À J+30, 31 % (15 sur 49) de ceux qui passeront une 3e commande l’ont déjà passée.

J+55

Après sa 2e commande. Il attend 81 jours en médiane avant la 3e. À J+55, 35 % (26 sur 75) de ceux qui passeront une 3e commande l’ont déjà passée.

Même logique : plus tard, car il est plus lent

J+60

Il est fidèle

Sans commande depuis 60 jours. À J+60, un fidèle a encore 25 % de chance de commander dans le mois (6 % pour un nouveau client) : il est encore actif, un rappel a du sens.

Sans commande depuis 120 jours. La chance est encore de 15 % à J+120 ; à J+180 elle tombe à 3,4 % (29 cas : trop peu pour conclure). Dernier mail à J+120, puis on arrête d’écrire.

Ce qu’on décide, et ce qui ferait changer d’avis.

Une relance selon le profil du client. Oui, mais pas au même moment pour tous : avant que la chance de retour ne baisse. Après 180 jours sans commande, on n’écrit plus.

def wilson(k, n_, z=1.96):
    if n_ == 0: return [None, None]
    p = k / n_; d = 1 + z * z / n_
    c = (p + z * z / (2 * n_)) / d; h = z * math.sqrt(p * (1 - p) / n_ + z * z / (4 * n_ * n_)) / d
    return [100 * (c - h), 100 * (c + h)]

def hazard(statut, T, H=30):
    """Observations = (client, commande) où le client a déjà passé `statut` commandes. Silence de T jours depuis cette commande ;
    succès = nouvelle commande dans les H jours suivants. On garde les observations suivies au moins T+H jours."""

    return {'T': T, 'retours': ok, 'observations': tot, 'taux': 100 * ok / tot if tot else None, 'ic': wilson(ok, tot)}

"""Base commune aux analyses de parcours client : lecture de orders.csv (hors commandes annulées),
familles de produits, clés produit, commandes rangées par client."""
import csv, re
from datetime import datetime
from collections import defaultdict

ORDERS_CSV = '../DONNEES/orders.csv'
REF = datetime(2026, 10, 23)

FAMILLES = ['Bougies gourmandes', 'Bougies boisson', 'Bougies taille S', 'Autres bougies', 'Fondants',
            'Voiture', 'Diffuseurs maison', 'Poudre parfumée', 'Élixirs', 'Accessoires et cadeaux', 'Formation']

def famille(name):
    n = name.upper()
    if n.startswith('BOUGIE GOURMANDE'): return 'Bougies gourmandes'
    if n.startswith(('BOUGIE BOISSON', 'BOUGIE LATTE', 'BOUGIE ICED')): return 'Bougies boisson'
    if n.startswith('BOUGIE PARFUMEE TAILLE S'): return 'Bougies taille S'
    if n.startswith('BOUGIE'): return 'Autres bougies'
    if n.startswith(('BOX DE FONDANTS', 'BOUQUET DE FONDANTS', 'TABLETTE', 'FONDANT')): return 'Fondants'
    if n.startswith(('SUSPENSION VOITURE', 'DIFFUSEUR VOITURE')): return 'Voiture'
    if n.startswith(('DIFFUSEUR', 'RECHARGE MELANGE')): return 'Diffuseurs maison'
    if n.startswith('POUDRE'): return 'Poudre parfumée'
    if n.startswith('ELIXIR'): return 'Élixirs'
    if n.startswith(('PACK FABRICATION', 'PACK BOUGIES')) or 'CONSULTING' in n or n.startswith('RÉGLEMENTATION') or n.startswith('REGLEMENTATION'): return 'Formation'
    return 'Accessoires et cadeaux'

def cle_produit(name):
    """Produit au sens marketing : on retire la variante après ' - ' ou ' / ' (parfum, taille)."""
    return re.split(r' - | / ', name)[0].strip()

def joli(s):
    t = s.replace('BOUGIE GOURMANDE ', 'Bougie ')
    t = t.translate(str.maketrans('ÉÈÊÀÂÎÔÛÇÏËÖ', 'éèêàâîôûçïëö')).lower()
    return t[0].upper() + t[1:]

def charger():
    """Retourne (commandes, clients) : commandes = liste de dicts ; clients = {cle: [commandes triées par date]}."""
    rows = []
    cur = None
    with open(ORDERS_CSV, encoding='utf-8') as f:
        for r in csv.DictReader(f):
            if r['Total']:
                cur = {'r': r, 'lignes': []}
                rows.append(cur)
            if cur and r['Lineitem name'] and r['Lineitem name'] != 'Tip':
                cur['lignes'].append({'nom': r['Lineitem name'], 'qte': int(r['Lineitem quantity']), 'prix': float(r['Lineitem price'])})
    commandes = []
    for o in rows:
        r = o['r']
        if r.get('Cancelled at'): continue
        sm = r['Shipping Method'] or ''
        d = {
            'date': r['Created at'][:10], 'dt': datetime.strptime(r['Created at'][:19], '%Y-%m-%d %H:%M:%S'),
            'cle': r['customer_key'].strip(), 'total': float(r['Total']), 'sous_total': float(r['Subtotal']),
            'code': r['Discount Code'] or '', 'remise': float(r['Discount Amount'] or 0),
            'local': 1 if re.match(r'^\d|otissement', sm) else 0,
            'pays': (r['Shipping Country'] or r['Billing Country'] or '').strip(),
            'cp': re.sub(r'\D', '', (r['Shipping Zip'] or r['Billing Zip'] or '')).zfill(5)[:5],
            'ordre_key': r['order_key'],
            'lignes': o['lignes'],
        }
        d['qte'] = sum(l['qte'] for l in d['lignes'])
        d['familles'] = sorted(set(famille(l['nom']) for l in d['lignes']))
        d['produits'] = sorted(set(cle_produit(l['nom']) for l in d['lignes']))
        val = defaultdict(float)
        for l in d['lignes']: val[famille(l['nom'])] += l['qte'] * l['prix']
        d['fam_dom'] = max(val.items(), key=lambda kv: kv[1])[0] if val else None
        d['prix_unit'] = (d['sous_total'] / d['qte']) if d['qte'] else None
        commandes.append(d)
    clients = defaultdict(list)
    for d in commandes:
        if d['cle'] and d['lignes']: clients[d['cle']].append(d)
    for v in clients.values(): v.sort(key=lambda d: d['dt'])
    for v in clients.values():
        for i, d in enumerate(v): d['rang'] = i + 1
    return commandes, clients
