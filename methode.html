Le code

Tous les scripts qui produisent les chiffres et les graphiques. Les fichiers de données ne sont pas fournis (confidentiels) : le code se lit, il ne se relance pas sans eux. Les chemins personnels ont été retirés à l’affichage. Chaque page affiche aussi les scripts qui la concernent.
