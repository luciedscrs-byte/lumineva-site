La question

La décision à prendre, posée en une phrase.

Comment pousser vers la 1re commande les abonnés qui n’ont jamais commandé ?

Pourquoi cette question ?

Constat 4 de « Choix et données ». Un code de −10 % est affiché à tous, et vous envoyez vos e-mails à plusieurs listes (FAQ) : à qui écrire, et avec quel code ?

2

L’hypothèse

Ce qu’on pense avant de calculer : c’est ce qu’on va vérifier.

Le code de bienvenue, affiché à tous, ne fait pas revenir ; les abonnés sans commande sont un groupe à relancer.

Notre hypothèse

Un code visible par tout le monde n’incite pas à revenir. Les abonnés qui n’ont jamais commandé ont montré de l’intérêt : un rappel ciblé a plus de chances de les faire passer à l’acte.

Test 2 · Sept critères testés à la fois : la correction de Holm

Quand on teste 7 choses, il y en a souvent une qui sort « significative » par pur hasard. La correction de Holm durcit le seuil pour éviter ce piège : un critère n’est retenu que si sa barre foncée reste à gauche de la ligne des 5 %.

Comment lire la valeur p ?

La valeur p est la chance de voir un tel écart si les deux groupes étaient identiques. Sous 5 %, l’écart est réel. Pour le code de bienvenue : p = 0,20 avant la correction, 0,60 après : on ne peut pas conclure.

D’où vient chaque nombre ?
  • Volume (693 abonnés) : un seul envoi aux abonnés sans commande, hors formation. Pour ce rappel, la remise moyenne du code (6,14 € par commande) est déduite de la marge.
  • Taux bas (0,11) : les newsletters ont rapporté 17 commandes pour 15 665 e-mails.
  • Taux haut (0,97) : les relances ont rapporté 7 commandes pour 722 e-mails.
  • Pourquoi ces deux taux ? Aucun des nouveaux mails n’a été testé : on prend comme bornes les deux taux mesurés dans la boutique, celui des newsletters (bas) et celui des relances (haut).
  • Panier moyen (62 €) : 99 629 € de chiffre d’affaires ÷ 1 595 commandes.
  • Marge : 50 % sur les bougies, 36 % à 50 % estimé sur l’ensemble des produits.
7

La décision

Ce qu’on décide, et ce qui ferait changer d’avis.

Un envoi unique aux 693, puis des étiquettes. En partie dès maintenant : les abonnés sans commande forment un segment Shopify. Pour les futurs inscrits, un Flow envoie le rappel tout seul. Ce qu’on ne peut pas faire : savoir d’où vient chaque abonné. Il faut des étiquettes.

Un formulaire général, des étiquettes automatiques, puis des rappels ciblés

1 · Envoi uniquerappel du code aux 693 abonnés existants (segment)
2 · Formulaireinscription générale à la newsletter (Shopify Forms)
3 · Étiquettesà l’inscription et à chaque code utilisé (Flow)
4 · Rappels automatiquespour les nouveaux inscrits (Flow)

Aujourd’hui : 32 commandes de clients existants ont utilisé le code de bienvenue (203 € de remises en 16 mois) et 55 commandes de fidèles ont utilisé un code (657 €) : avec des étiquettes, on peut les exclure.

Ce qui ferait changer d’avis

Si le rappel ne fait pas mieux qu’une newsletter (0,11 commande pour 100 e-mails), le code seul ne suffit pas.

Limites et ce qui manque

  • Les 650 abonnés sans étiquette ont une origine inconnue : on ne sait pas s’ils ont vu le code.
  • Le rappel du code est une proposition : son effet n’est pas démontré (le code de bienvenue actuel ne fait pas revenir plus).
  • Le déclencheur « un client entre dans un segment » et le filtre sur l’étiquette sont à vérifier dans la boutique avant de construire le Flow.
