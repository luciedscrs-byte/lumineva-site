Comment automatiser la retouche photo ?

Aujourd’hui les ombres sont corrigées photo par photo : combien de photos sont concernées, et quelle solution gratuite adopter.

En sept lignes

ÉtapePour cette question
La questionFaut-il automatiser la retouche des ombres, et comment ?
L’hypothèseLe volume de photos est assez grand et régulier pour qu’un outil par lots fasse gagner un temps utile.
Le périmètre133 produits actifs, 210 sorties de produits en 12 mois.
Le testComptage des photos par produit et des sorties par mois ; heures selon 3 temps par photo ; comparaison des outils (sources en bas).
L’effetEnviron 531 photos par an ; 58 % des sorties en 3 mois.
Le chiffreDe 18 à 88 heures par an (2 à 10 minutes par photo, hypothèse).
La décisionOui, avec une solution gratuite par lots, après avoir limité les ombres à la source. Décider après avoir chronométré 20 photos.

Niveau de preuve : Estimation : le volume est estimé et le temps par photo inconnu ; aucun effet des photos sur les ventes n’est mesuré

  • FaitAujourd’hui (séance avec la gérante) : les ombres sont corrigées une photo à la fois avec ChatGPT (abonnement payant) ; elle est ouverte à automatiser.
  • FaitLe catalogue compte 133 produits actifs et 271 photos (2,0 par produit). Le travail arrive par vagues : novembre 2025 (56 produits), mars 2026 (29), septembre 2026 (36).
  • Interprétation possibleL’intérêt est réel mais modéré : quelques dizaines d’heures par an, concentrées sur 3 ou 4 lancements. Cela justifie une solution gratuite par lots, pas un abonnement ni un développement sur mesure.
  • LimiteLes solutions gratuites éclaircissent les ombres ; nous n’avons pas trouvé d’outil gratuit par lots qui supprime une ombre portée : le plus sûr est de l’éviter à la prise de vue.

Les solutions, de la plus simple à la plus poussée

Sources consultées le 12 novembre 2026 : Photoroom, Shopify, darktable, Adobe. Les prix changent : à vérifier.

Ce qu’on conseille

  • Éviter les ombres à la source : éclairage doux et constant, fond clair uni.
  • Chronométrer 20 photos retouchées comme aujourd’hui, puis les passer dans le programme gratuit (python3 retouche_ombres.py mon_dossier --apercu, réglage --force de 0,3 à 1).
  • Garder la solution gratuite si le temps par photo est au moins divisé par deux et si aucun rendu n’est à refaire ; relire chaque lot (couleur de la cire, étiquettes). Sinon, garder ChatGPT pour les photos à ombre portée.

Limites et ce qui manque

  • Le temps par photo et le coût de l’abonnement actuel sont inconnus.
  • Le programme a été essayé sur 3 captures d’e-mails, pas sur de vraies photos de produits.
  • Le nombre de photos est une estimation : 178 des 210 produits seulement se relient au catalogue par leur nom.

# encoding: utf-8
"""Retouche photo : combien de photos faut-il retoucher, et quand ? (agrégats seulement)
Sources : products.csv (photos par produit, au 22/10/2026) et orders.csv (date de première vente d'un produit = sortie du produit).
Limite : une « sortie » est la date de première vente ; le nom du produit sert de clé (la variante est retirée)."""
import csv, json, re, unicodedata, collections, statistics as st

D = '../DONNEES/'
def norm(s):
    s = unicodedata.normalize('NFKD', s).encode('ascii', 'ignore').decode().upper()
    return re.sub(r'\s+', ' ', re.sub(r'[^A-Z0-9 ]', ' ', s)).strip()

imgs, info, cur = collections.defaultdict(set), {}, None
for r in csv.DictReader(open(D + 'products.csv', encoding='utf-8')):
    if r['Status']: cur = r['Handle']; info[cur] = {'t': r['Title'], 's': r['Status']}
    if r['Image Src']: imgs[cur].add(r['Image Src'])
actifs = [h for h, d in info.items() if d['s'] == 'active']
n_act = [len(imgs[h]) for h in actifs]
tit = {norm(d['t']): h for h, d in info.items()}

premiere = {}
cur = None
for r in csv.DictReader(open(D + 'orders.csv', encoding='utf-8')):
    if r['Total']: cur = r
    if cur and r['Lineitem name'] and r['Lineitem name'] != 'Tip' and not cur['Cancelled at']:
        k = norm(re.split(r' - | / ', r['Lineitem name'])[0]); d = cur['Created at'][:10]
        if k not in premiere or d < premiere[k]: premiere[k] = d
# on écarte le tout premier mois (produits d'ouverture de la boutique)
sorties = {k: d for k, d in premiere.items() if d > '2025-06-30'}
par_mois = collections.Counter(d[:7] for d in sorties.values())
douze = {k: d for k, d in sorties.items() if d >= '2025-11-01'}
reliees = [len(imgs[tit[k]]) for k in douze if k in tit]
jours = collections.Counter(d for d in sorties.values())
vagues_jours = sorted((d, c) for d, c in jours.items() if c >= 20)
n_nouveaux = len(douze); photos_par_produit = st.mean(reliees)
photos_an = round(n_nouveaux * photos_par_produit)
vagues_mois = sorted((m, c) for m, c in par_mois.items() if m >= '2025-11' and c >= 25)
sc = [{'minutes': m, 'heures_an': round(photos_an * m / 60), 'heures_vague': round(60 * 0 + (photos_an / 4) * m / 60, 1)} for m in (2, 5, 10)]
out = {'produits_actifs': len(actifs), 'photos_actifs': sum(n_act), 'photos_par_produit_actifs': round(st.mean(n_act), 1), 'sans_photo': sum(1 for x in n_act if x == 0),
       'brouillons': sum(1 for d in info.values() if d['s'] == 'draft'),
       'sorties_12_mois': n_nouveaux, 'reliees_catalogue': len(reliees), 'photos_par_produit_nouveaux': round(photos_par_produit, 1),
       'photos_an': photos_an, 'par_mois': dict(sorted(par_mois.items())), 'jours_de_sortie': vagues_jours, 'mois_vagues': vagues_mois,
       'part_dans_vagues': round(100 * sum(c for m, c in par_mois.items() if m >= '2025-11' and c >= 25) / n_nouveaux),
       'scenarios': sc}
json.dump(out, open('q3_photos.json', 'w'), ensure_ascii=False, indent=1)
print(json.dumps(out, ensure_ascii=False, indent=1)[:2500])

# encoding: utf-8
"""Éclaircit les ombres d'un dossier de photos, en une seule commande (gratuit, sans abonnement).

Usage :
    python3 retouche_ombres.py photos_brutes                      # écrit dans photos_brutes/retouchees
    python3 retouche_ombres.py photos_brutes sortie --force 0.7   # plus fort (0 = rien, 1 = fort)
    python3 retouche_ombres.py photos_brutes --apercu             # ajoute un fichier « avant | après » pour vérifier

Ce que fait le programme : il éclaircit les zones sombres, avec un masque très flou pour ne pas créer de halo,
et laisse les hautes lumières intactes. Les photos d'origine ne sont jamais modifiées.
Ce qu'il ne fait pas : il ne supprime pas une ombre portée (l'ombre d'un objet sur la table) ; il ne change pas le fond.
Il faut relire chaque photo avant de la publier (couleur de la cire, étiquettes lisibles).
Installation, une seule fois :  pip3 install pillow numpy   (Windows : py -m pip install pillow numpy)"""
import argparse, os, sys
import numpy as np
from PIL import Image, ImageFilter, ImageOps

EXTENSIONS = ('.jpg', '.jpeg', '.png', '.webp')


def eclaircir_ombres(img, force):
    """img : image PIL RGB ; force : de 0 (rien) à 1 (fort). Retourne une image PIL RGB."""
    a = np.asarray(img, dtype=np.float32) / 255.0
    lum = 0.2126 * a[..., 0] + 0.7152 * a[..., 1] + 0.0722 * a[..., 2]
    # masque : fort dans les zones sombres, nul dans les clairs, très flou (pas de halo autour des objets)
    flou = Image.fromarray((lum * 255).astype(np.uint8)).filter(ImageFilter.GaussianBlur(max(img.size) / 60))
    masque = (1.0 - np.asarray(flou, dtype=np.float32) / 255.0) ** 2
    masque = np.clip(masque * (0.6 + 0.8 * force), 0, 1)[..., None]
    gamma = 1.0 / (1.0 + 0.9 * force)                       # < 1 : éclaircit les tons sombres
    eclairci = np.power(np.clip(a, 1e-4, 1), gamma)
    sortie = a * (1 - masque) + eclairci * masque
    return Image.fromarray(np.clip(sortie * 255 + 0.5, 0, 255).astype(np.uint8))


def main():
    p = argparse.ArgumentParser(description="Éclaircit les ombres d'un dossier de photos.")
    p.add_argument('entree', help='dossier des photos brutes')
    p.add_argument('sortie', nargs='?', help='dossier de sortie (par défaut : entree/retouchees)')
    p.add_argument('--force', type=float, default=0.6, help='de 0 à 1 (par défaut 0,6)')
    p.add_argument('--apercu', action='store_true', help="écrit aussi une image « avant | après » par photo")
    a = p.parse_args()
    sortie = a.sortie or os.path.join(a.entree, 'retouchees')
    os.makedirs(sortie, exist_ok=True)
    fichiers = sorted(f for f in os.listdir(a.entree) if f.lower().endswith(EXTENSIONS))
    if not fichiers:
        sys.exit('Aucune photo (.jpg, .png, .webp) dans ' + a.entree)
    for f in fichiers:
        img = ImageOps.exif_transpose(Image.open(os.path.join(a.entree, f))).convert('RGB')
        res = eclaircir_ombres(img, a.force)
        nom = os.path.splitext(f)[0]
        res.save(os.path.join(sortie, nom + '.jpg'), quality=95, subsampling=0)
        if a.apercu:
            duo = Image.new('RGB', (img.width * 2, img.height)); duo.paste(img, (0, 0)); duo.paste(res, (img.width, 0))
            duo.save(os.path.join(sortie, nom + '_avant-apres.jpg'), quality=90)
        print('ok', f)
    print(len(fichiers), 'photo(s) retouchée(s) ->', sortie)


if __name__ == '__main__':
    main()
