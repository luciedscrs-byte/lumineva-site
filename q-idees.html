Toutes les idées étudiées

Toutes les idées d’automatisation étudiées depuis le début, passées au crible de quatre critères : celles qu’on recommande, celles qu’on teste, celles qu’on écarte, avec la raison.

En clair

La question. Quelles automatisations peut-on proposer avec seulement les données qu’on a ?

Notre réponse. 18 idées examinées. 7 sont retenues (relance par profil, relances panier et paiement, rappel de code, code réservé, formulaire général…), 3 sont à tester (parcours de 3 mois, alerte de retour en stock, demande d’avis une fois la réponse du prof connue) et 8 sont écartées parce qu’un chiffre les contredit ou parce que leur effet ne peut pas se prouver.

Les chiffres qui la soutiennent :

  1. Une idée n’est retenue que si les quatre critères sont remplis. Seules 8 idées sur 18 les remplissent tous : 7 sont retenues, 1 à tester (effet non prouvé).
  2. Les idées écartées le sont par un chiffre : par exemple l’e-mail de lancement (0,06 commande pour 100 e-mails) ou l’alerte de stock bas (62 % du catalogue déjà concerné).
  3. Toutes les données ont été utilisées ou examinées : un seul fichier ne sert à rien ici (âge et genre des abonnés des réseaux).

4 · Détail d’une idée retenue : réserver le code de bienvenue aux clients sans commande

447 sur 9131res commandes avec le code de bienvenue (−10 %)
32commandes avec ce code passées par des clients qui avaient déjà commandé
203 €de remises sur ces 32 commandes (environ 152 € par an)
4 sur 60codes de la boutique déjà réservés à des clients précis
  • FaitLe code est réglé « une utilisation par client », ce qui est bien. Mais n’importe quel client qui ne l’a jamais utilisé peut s’en servir, y compris après plusieurs commandes : 32 commandes sur 482 (7 %), au rang médian 2 (2e commande).
  • FaitLe code n’a pas de date de fin : premier usage le 21/07/2025, dernier le 20/10/2026.
  • FaitLa boutique sait déjà réserver un code à des clients précis (4 codes de ce type dans discounts.csv) : ce réglage existe dans l’outil.
  • Interprétation possibleLe gain est petit (environ 152 € par an) mais il est certain et sans effort : un réglage, aucun e-mail. On ne sait pas si ces clients auraient commandé sans le code.
  • LimiteUn client qui s’inscrit à la newsletter avant de commander reste éligible : la règle « zéro commande » ne l’exclut pas.

Limites et ce qui manque

  • Les 32 commandes sont comptées dans les 16 mois de données ; le rythme futur peut changer.
  • La marge sur ces commandes est inconnue : les 203 € sont une remise facturée, pas une perte de marge exacte.

def wilson(k, n_, z=1.96):
    if n_ == 0: return [None, None]
    p = k / n_; d = 1 + z * z / n_
    c = (p + z * z / (2 * n_)) / d; h = z * math.sqrt(p * (1 - p) / n_ + z * z / (4 * n_ * n_)) / d
    return [100 * (c - h), 100 * (c + h)]


def fisher(a, na, b, nb):
    return float(stats.fisher_exact([[a, na - a], [b, nb - b]])[1])

def hazard(statut, T, H=30):
    """Observations = (client, commande) où le client a déjà passé `statut` commandes. Silence de T jours depuis cette commande ;
    succès = nouvelle commande dans les H jours suivants. On garde les observations suivies au moins T+H jours."""
    ok = tot = 0
    for v in clients.values():
        for i in range(len(v)):
            if not statut(i + 1): continue
            last = v[i]['dt']; nxt = v[i + 1]['dt'] if i + 1 < len(v) else None
            if (REF - last).days < T + H: continue
            if nxt is not None and (nxt - last).days <= T: continue
            tot += 1; ok += 1 if (nxt is not None and (nxt - last).days <= T + H) else 0
    return {'T': T, 'retours': ok, 'observations': tot, 'taux': 100 * ok / tot if tot else None, 'ic': wilson(ok, tot)}

def base90(filtre_rang, jours=90):
    """Après une commande de rang filtré, combien d'articles et d'euros le client achète-t-il dans les `jours` jours suivants ? (clients suivis au moins `jours` jours)"""
    art, eur_, cmdn, n_ = [], [], [], 0

    return {'observations': len(art), 'articles_moy': float(np.mean(art)), 'euros_moy': float(np.mean(eur_)), 'commandes_moy': float(np.mean(cmdn))}
