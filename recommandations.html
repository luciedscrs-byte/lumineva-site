Quatre questions, quatre automatisations

Recommandations

Pour chaque question posée aux données, l’automatisation qu’on recommande à Lumineva, présentée comme un tableau de suivi : quand le mail part, pour qui, ce qu’il dit, ce qui se passe ensuite, et comment le régler dans Shopify.

En clair

La question. Quelles automatisations recommander à Lumineva, et comment les mettre en place sur Shopify ?

Notre réponse. Une automatisation par question : la relance selon le profil, les paniers et paiements en deux temps, le rappel de code par étiquette et l’alerte de commande non expédiée. Même quand la réponse est négative (pas d’e-mail de lancement), elle débouche sur une automatisation utile. Toutes se règlent dans Shopify (Messaging, Flow, segments) et partent d’une donnée de la boutique.

Les chiffres qui la soutiennent :

  1. Besoin : Lumineva n’a que 7 automatisations (4 actives, une avec son e-mail resté en brouillon) ; seules les relances de panier et de paiement ont rapporté des commandes (7 commandes, 842 €).
  2. Temps : la gérante dit manquer de temps ; ces automatisations tournent sans elle. Le temps gagné n’est mesuré dans aucun fichier : voir la dernière section.
  3. Argent : faible et non prouvé (voir les pages de questions). Ce n’est pas l’argument principal.

Niveau de preuve : Démontré pour les chiffres cités ; Hypothèse pour l’effet des mails et le temps gagné

Recommandations complémentaires

Ce qu’on conseille en plus

  • Ajouter un formulaire d’inscription général à la newsletter (Shopify Forms, en bas de page par exemple) : le seul formulaire visible sur le site est celui de la formation. Une liste qui a choisi les bougies manque aujourd’hui à la boutique.
  • Inciter à accepter les e-mails au moment de la commande : 19 % des clients (173 sur 913) ne peuvent pas être relancés.
  • Réserver le code de bienvenue aux clients sans commande (réglage du code).
  • Relever chaque mois les chiffres de chaque automatisation (tableau plus bas).

Pas à pas dans Shopify

Les chemins de menu sont décrits d’après l’aide de Shopify ; les noms exacts peuvent différer légèrement dans la boutique de Lumineva. Rien n’a été testé. On suppose que Lumineva utilise Flow (gratuit) ; sinon on le lui conseille.

Créer un segment (exemple : les nouveaux clients à relancer à J+45)

  1. Dans l’administration Shopify : Clients, puis Segments, puis Créer un segment.
  2. Écrire les conditions (Shopify les propose dans une liste ; voir la référence des segments) : nombre de commandes = 1, dernière commande il y a 45 jours, abonné aux e-mails.
  3. Enregistrer le segment sous un nom clair, par exemple « R1 nouveau J+45 ».

Les noms exacts des conditions sont à vérifier dans l’éditeur de segments de la boutique.

Créer un Flow qui ajoute un tag (exemple : T2 « régulier »)

  1. Applications, puis Flow, puis Créer un workflow.
  2. Choisir le déclencheur « Commande créée ».
  3. Ajouter une condition : le nombre de commandes du client est supérieur ou égal à 3.
  4. Ajouter l’action « Ajouter des tags au client » avec le tag « regulier ».
  5. Nommer le workflow (« T2 tag régulier »), puis l’activer.

Rappeler un code seulement à ceux qui ne l’ont pas utilisé (questions 3, campagnes)

  1. Créer le code dans Réductions (par exemple PRINTEMPS10).
  2. Créer le Flow T3 : « Commande créée », condition « le code de réduction est PRINTEMPS10 », action « tag client » : « code-PRINTEMPS10 ».
  3. Dans Clients, Segments : abonné aux e-mails et sans le tag « code-PRINTEMPS10 ».
  4. Dans Marketing, Automatisations (ou une campagne) : envoyer le rappel à ce segment.

Créer le rappel unique du code de bienvenue (RC1)

  1. Applications, Flow, Créer un workflow : déclencheur « Client abonné aux e-mails » (nom exact à vérifier).
  2. Action « Attendre » : 7 jours.
  3. Condition : le client a 0 commande et n’a pas l’étiquette « Formation ».
  4. Action : envoyer l’e-mail « Ton −10 % t’attend toujours » (Shopify Messaging). Activer.

L’envoi d’un e-mail marketing depuis Flow ne part qu’aux clients abonnés (d’après des forums, à vérifier).

Créer le Flow d’alerte (T4 : commande non expédiée après 7 jours)

  1. Applications, Flow, Créer un workflow, déclencheur « Commande créée ».
  2. Ajouter l’action « Attendre » : 7 jours (le maximum est de 90 jours).
  3. Ajouter une condition : l’état d’expédition de la commande n’est pas « expédié ».
  4. Si oui : action « Envoyer un e-mail interne » (à la gérante) et « Ajouter un tag à la commande » : « retard-7j ». Activer.

L’action « envoyer un e-mail interne » n’a pas pu être confirmée dans l’aide de Shopify : à vérifier dans l’éditeur.

Limites et ce qui manque

  • Aucun effet de ces mails n’est démontré : les chiffres cités sont la situation de départ, pas un résultat promis.
  • Les délais (+24 h, J+7…) sont des propositions, sauf pour la relance par profil, déduite des courbes de retour.
  • Les noms de menus et d’actions Shopify viennent de la documentation et de forums : à vérifier dans la boutique avant de présenter.
  • Lumineva n’envoie de mail « marketing » qu’aux abonnés (81 % des clients) ; les autres n’ont droit qu’aux mails de commande.
